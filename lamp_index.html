ESP32 / Arduino PID Kod Tizimi

Xoll datchigidan (Hall Sensor) kelayotgan qiymatlarni o'qib, elektromagnitga beriladigan kuchlanishni (PWM) PID regulyator orqali boshqarish kodi:

// Arduino PID Levitation Control Loop double Kp = 12.0, Ki = 0.15, Kd = 6.0; double setpoint = 512; // Xoll datchigining normal nuqtasi double integral = 0, lastError = 0; void loop() { double currentPos = analogRead(A0); // Xoll datchigidan o'qish double error = setpoint - currentPos; integral += error; double derivative = error - lastError; double output = (Kp * error) + (Ki * integral) + (Kd * derivative); lastError = error; // PWM signal yuborish (Mosfet orqali elektromagnitni boshqarish) analogWrite(PWM_PIN, constrain(output, 0, 255)); delay(1); // 1KHz chastota }

Simsiz Quvvat & Bluetooth Audio

**Wireless induction link**: Stend ichiga 12V Induktsion g'altak va generator platasi, shar ichiga esa qabul qiluvchi kichik g'altak (receiver module) va 5V stabilizator platasi o'rnatiladi.

**Audio**: Shar ichiga juda kichik 3W quvvatli Bluetooth 5.0 audio chipi va kichik sharsimon akustik qutiga ega dinamik joylashtiriladi. Energiya to'liq havo orqali kelayotgan induksion tokdan olinadi.

Kerakli komponentlar ro'yxati:
• Mikrokontroller: ESP32 yoki Arduino Nano
• Datchik: AH3503 linear Hall sensor
• Elektromagnit: 12V 5kg ushlab turish kuchi
• Drayver: IRF540N Mosfet moduli
• Simsiz zaryad: 12V Transmitter + 5V Receiver kiti
• Dinamik: 3W, 4 Ohm diametri 40mm
